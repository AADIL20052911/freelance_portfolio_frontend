# Freelance Portfolio Frontend

A modern, responsive portfolio built with React, Tailwind CSS, and Framer Motion.

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start development server:
   ```bash
   npm run dev
   ```

## Notes

- The frontend proxies API requests to `http://localhost:5000/api`.
- Update links and contact information in `src/components/Contact.jsx` and `src/components/Navbar.jsx`.
